# 👻 GhostLy Community & Feedback

Welcome to the **GhostLy Community Hub**. This is the official space for reporting bugs, suggesting spectral features, and discussing the future of context-aware productivity on macOS.

---

## 🌩️ How to Manifest Your Feedback

GhostLy thrives on the feedback of its users. Whether you've found a glitch in the matrix or have an idea for a new "spectral" ability, we want to hear it.

### 🐞 Reporting Bugs
Found something broken? Please open a [Bug Report](https://github.com/kcode-apps/ghostly-community/issues/new?template=bug_report.md).
*   **Be Descriptive**: What were you doing when the bug appeared?
*   **Context**: Which macOS version and AI provider (Claude, GPT, etc.) were you using?
*   **Logs**: If possible, include any relevant output from the app's settings or console.

### 💡 Suggesting Features
Have an idea to make GhostLy more powerful? Open a [Feature Request](https://github.com/kcode-apps/ghostly-community/issues/new?template=feature_request.md).
*   **The "Why"**: How will this feature help you stay focused?
*   **The "How"**: Any ideas on how the UI or logic should handle it?

### 💬 Discussions & Support
Not sure if something is a bug? Want to share how you use GhostLy? Use the [Discussions](https://github.com/kcode-apps/ghostly-community/discussions) tab.

---

## 🛡️ Privacy & Safety
**GhostLy is built on a local-first, privacy-respecting philosophy.**
*   **NEVER** post screenshots containing sensitive information (Passwords, PII, API Keys) in public issues.
*   **Logs**: Before posting logs, scan them for any personal information you wouldn't want to be public.
*   **Security**: If you find a security vulnerability, please do **NOT** open a public issue. Email us directly at `security@ghostlydesktop.com`.
